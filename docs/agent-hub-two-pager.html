One HUB. Every agent.

This is not one large AI application. It is a generic agent execution platform with workflows installed on it — which is why the next use case is a set of files, not a release.

The separation that makes it a platform

Platform
Submits jobs, runs containers, authenticates, stores results, tracks status, enforces limits and security.
Skill
Knows a domain — how test-case generation, or document OCR, is actually done.
Agent
Knows one step of reasoning, and declares the only tools it is allowed to touch.

Each layer knows only the one beneath it — the orchestrator cannot tell whether generation used Copilot or the mock engine, and the runner cannot tell what started it.

Drop a file in, the registry reconciles it against registry.yaml, and it is live in the catalog, the Console picker and the job API — no redeploy, no migration. A workflow naming an agent that does not exist is rejected at write time.

Execution model

  • 1 req = 1 JobNo shared long-lived process — isolation, cleanup, per-job limits, honest retries.
  • leased rowClaimed by conditional UPDATE and renewed while it runs, never a background task; a dead replica’s jobs return to the queue.
  • transition()An illegal state move raises; every move appends a job_events row.
  • 3 executorslocal, docker and kubernetes behind one protocol — the cluster path calls the API, never kubectl.

Trust boundary — the requirement is attacker-controlled text

  • data, not instructionEmbedded directives are ignored and recorded under assumptions.
  • no shell / no fetchThe registry refuses to persist an agent declaring either.
  • no interpolationInput is a file referenced by path, never part of a command line.
  • confinementNon-root, caps dropped, /workspace only, default-deny egress.
  • output distrustedNothing completes a job until it is schema- and rule-validated.
QUEUED→ STARTING→ ANALYZING→ AWAITING_APPROVAL→ RUNNING→ VALIDATING→ EVALUATING→ COMPLETED Any in-flight state may end FAILED · TIMEOUT · CANCELLED; the human gate refuses with REJECTED.
